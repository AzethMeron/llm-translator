# Pinned Python environment for the general translator.
#
# Recreate with: tools/setup_python_env.sh
#
# The dependency footprint is deliberately tiny and split by package, because the two
# packages are separately usable and their needs differ sharply:
#
#   transunit   stdlib only -- the intermediate format, terminology, placeholder
#               convention, display width, and language detection. Nothing below is
#               required to read a catalogue, group duplicates, or decide whether a
#               translation is still in its source language. Enforced by
#               tests/test_separation.py, which imports the whole contract with httpx
#               unimportable.
#   translator  needs one thing: an HTTP client to reach a local, OpenAI-compatible
#               inference server (llama.cpp, ollama, vLLM, ...).
#
# Every package is pinned exactly, transitive ones included. Pinning only the direct
# dependencies leaves the actual installed set free to drift, which is the drift that
# makes a months-old run impossible to reproduce.
